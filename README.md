# Sustainability-Cell-WEB-Assignment

## Brief Description
This repository contains my submission for the Sustainability Cell Web Convener Assignment. It includes a redesigned hero section for the Sustainability Cell website and a proposal for an interactive sustainability map for IIT Bombay.

### Q1: Hero Section Redesign
For Question 1, I created an improved hero section for the Sustainability Cell website while keeping the existing sustainability theme. My goal was to make the landing page more modern, engaging, and visually appealing while still maintaining the identity of the original website. The redesign focuses on stronger typography, better visual hierarchy, interactive elements, and a cleaner overall layout. I also included motion/animation to make the hero section feel more dynamic and visually interesting. The project is meant as a concept/prototype showing how the official hero section could be improved for better first impressions and user engagement.

This part of the project was created with the help of **Claude AI** with my own editing, design decisions, and implementation choices.

### Q2: Ideating Sustainability Map for IIT Bombay
This project is a proposal for an interactive sustainability map for IIT Bombay. It is meant to help students easily find sustainability-related facilities and initiatives on campus, such as biogas plants, recycling points, dustbins, and other eco-friendly locations. The aim is to make these places more visible, accessible, and useful for students.
